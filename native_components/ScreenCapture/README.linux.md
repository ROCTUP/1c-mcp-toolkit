# ScreenCapture — 1C Native API Component (Linux)

C++ компонента для 1С:Предприятие. Делает скриншот основного окна клиента 1С, включая открытые меню, списки выбора и диалоги. Используется инструментом `get_screenshot`.

Поддерживает PNG/Base64, масштабирование, обрезку области, координатную сетку и пронумерованные прямоугольники подсветки.

## Требования

- Linux (x86_64), клиент 1С с графическим интерфейсом
- X11 или Xwayland, включённый композитинг окон
- Расширения XRes 1.2+, Composite 0.2+ и Render
- Docker — для сборки; на Windows — Docker Desktop в режиме Linux-контейнеров

На машине с клиентом 1С установите зависимости (Ubuntu/Debian):

```bash
sudo apt-get install libxcb1 libxcb-res0 libxcb-composite0 libxcb-render0 libxcb-shape0
```

## Сборка под Linux (через Docker)

Запустите из корня репозитория.

На Windows:

```bat
native_components\ScreenCapture\build_linux.bat
```

На Linux/macOS:

```bash
bash native_components/ScreenCapture/build_linux.sh
```

Результат: `native_components/ScreenCapture/build_linux/ScreenCapture.so`.

База образа — Ubuntu 20.04 (glibc 2.31), компилятор GCC 9. Библиотека miniz для кодирования PNG скачивается автоматически при первой сборке.

## Установка в обработку

Скопируйте `.so` в макет обработки под именем `Template.bin`:

```bash
cd native_components/ScreenCapture
cp build_linux/ScreenCapture.so \
   ../../1c/MCPToolkit/MCPToolkit/Templates/ScreenCapture/Ext/Template.bin
```

После обновления `Template.bin` нужно пересохранить обработку в конфигураторе 1С и заново открыть её в клиенте.

## API

### Методы

| Метод (EN) | Метод (RU) | Возврат | Описание |
|-----------|-----------|---------|----------|
| `CaptureWindow(scale, showGrid, regionX, regionY, regionW, regionH, highlightRects)` | `ЗахватитьОкно` | Строка | Снимок основного окна 1С с метаданными |

### CaptureWindow / ЗахватитьОкно

| Параметр | Тип | Описание |
|----------|-----|----------|
| `scale` | Число | Масштаб 10–200%; 100 — исходный размер |
| `showGrid` | Булево | Наложить координатную сетку; по умолчанию `Ложь` |
| `regionX`, `regionY` | Число | Координаты начала области в пикселях клиентской области основного окна |
| `regionW`, `regionH` | Число | Ширина и высота области; для полного окна все четыре параметра области равны `-1` (по умолчанию) |
| `highlightRects` | Строка | Прямоугольники в формате `x,y,width,height;x,y,width,height`; по умолчанию пустая строка |

Обрезка выполняется до масштабирования. Координаты сетки и прямоугольников задаются относительно исходной клиентской области окна. Прямоугольники должны находиться внутри захватываемой области и не пересекаться; максимум — 20.

Результат:

```text
V2|<длина JSON>|<JSON с метаданными>|<PNG в Base64>
```

Метаданные содержат положение области (`window_rect`), координаты сетки (`grid_coords`, если включена), сведения о всплывающих окнах (`overlays`) и полноте захвата (`capture_complete`, `overlay_failures`). Обработка MCP Toolkit разбирает результат и возвращает изображение через `get_screenshot`.

При ошибке возвращается строка `ERROR:...`, при временной невозможности захвата — `RETRY:...`.

## Особенности Linux

- Окно 1С можно захватить, когда оно перекрыто другим приложением. Чужие окна в снимок не попадают.
- Свёрнутое окно не захватывается.
- Снимок ограничен клиентской областью основного окна. Части меню и диалогов за её пределами обрезаются.
- Нативные окна Wayland не поддерживаются; в сессии Wayland клиент 1С должен работать через Xwayland.
- Курсор мыши и эффекты композитного менеджера (тени, размытие) в снимок не включаются.

Если компонента не загружается, проверьте зависимости собранного файла:

```bash
ldd -r native_components/ScreenCapture/build_linux/ScreenCapture.so
```

Ошибка `ERROR:x11:window_not_redirected` означает, что недоступны буферы окон: проверьте, включён ли композитинг. Ошибка `ERROR:x11:unsupported_transparency` означает, что захватываемая область основного окна содержит прозрачные участки.
